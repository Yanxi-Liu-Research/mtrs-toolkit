Module 01

MTRS — ranking stability

Inputs

Input Meaning
matrix Decision matrix: scenarios × indicators
weights Nominal indicator weights (normalised internally)
directions +1 higher-better, −1 lower-better per indicator
spec Uncertainty specification for the six sources

The six uncertainty sources

Source Ensemble construction
parameter Lognormal multiplicative noise, expectation 1, per indicator
data_year Alternative data vintages as scenario × indicator shift matrices
model_structure Alternative decision matrices from different model structures
policy_mapping Alternative scenario-to-indicator mapping matrices
weight Indicator weights drawn from a Dirichlet around the nominal weights
area_structure The scenarios under alternative metropolitan-area structures

Decision rules

Rule Condition (defaults, configurable)
Reportable as stable S ≥ 0.80 and reversal p ≤ 0.10
Reversal risk top-rank flip probability p > 0.10
Transferable across areas transfer failure rate ≤ 0.30
The headline verdict is STABLE, REVERSAL or NON-TRANSFERABLE, evaluated in that priority order. A ranking that fails the stability threshold but shows no clean reversal is conservatively reported as NON-TRANSFERABLE.

Minimal example

Python 
from mtrs import MTRSAnalysis, UncertaintySpec, render_text_report
matrix = [
    [78, 64, 55, 42, 38, 71],
    [69, 58, 61, 30, 44, 64],
    [58, 71, 66, 35, 36, 52],
    [64, 45, 41, 22, 40, 57],
    [40, 40, 40, 26, 30, 40],
]
analysis = MTRSAnalysis(
    matrix,
    scenario_names=["Metro extension", "BRT network",
                    "Road pricing + transit", "TOD intensification", "Baseline"],
    indicator_names=["accessibility", "emissions", "time saving",
                     "cost per trip", "safety", "ridership"],
    weights=[0.20, 0.15, 0.25, 0.15, 0.10, 0.15],
    directions=[1, 1, 1, -1, 1, 1],
    spec=UncertaintySpec(parameter={"sigma": 0.06}),
)
result = analysis.run(n_draws=1000, seed=42)
print(render_text_report(result))

Stability score

Stability score: S = 1 − D / D_max, where D is the mean total rank displacement over the ensemble and D_max = floor(n²/2).

Module 02

SDI-BCA — staged-delay benefit-cost analysis

Stage model

Stages form a directed dependency graph. A stage opens when its own construction is complete and every prerequisite is operational (plus an optional handover lag). Costs accrue uniformly over construction; benefits accrue from the opening year with an optional linear ramp-up. Discounting is end-of-year.

Outputs

Output Meaning
base / delayed NPV, BCR Programme value with and without the delay schedule
ΔNPV, ΔBCR Total delay impact
marginal NPV impact of each delayed stage alone
interaction ΔNPV − Σ marginals: the staged-delay interaction term

Minimal example

Python 
from sdibca import SDIBCAModel, Stage
stages = [
    Stage("BRT corridor", 0, 2, annual_cost=40, annual_benefit=35, ramp_up=1.0),
    Stage("Fare integration", 1, 1, annual_cost=8, annual_benefit=10,
          ramp_up=0.5, handover_lag=0.5, depends_on=("BRT corridor",)),
    Stage("LRT extension", 3, 3, annual_cost=55, annual_benefit=60,
          ramp_up=1.5, depends_on=("BRT corridor", "Fare integration")),
]
model = SDIBCAModel(stages, discount_rate=0.05, horizon=20)
result = model.analyse({"BRT corridor": 1.0})
print(result.base["npv"], result.delayed["npv"], result.delta_npv)

Execution

Reproducibility

All randomness flows from a single seed passed to MTRSAnalysis.run(). Identical inputs and seed reproduce identical results; the shipped examples pin their seeds. Reports embed the seed and the number of draws per source.
