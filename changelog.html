Changelog

Version history

Every release of the toolkit, from the initial MTRS implementation to the open-source v1.4.0.

v1.4.0 — open-source release 2026-03-20
  • Published the complete source under the MIT License on GitHub.
  • Launched the public documentation and distribution site.
  • Packaged distribution (pyproject.toml, pip-installable).
  • Example datasets and unit-test suite shipped with the source.
v1.3.0 2025-12-08
  • Parallel ensemble evaluation: six-source draws now run independently per source.
  • Machine-readable JSON report schema (mtrs/report.py).
  • Download telemetry for the self-hosted distribution server.
  • Deterministic seeding documented and pinned in all examples.
v1.2.0 — SDI-BCA joins the toolkit 2025-06-18
  • Added the SDI-BCA module: staged dependency graphs, delay propagation, NPV/BCR with marginal delay decomposition and the staged-delay interaction term.
  • SDI-BCA follows the procedure of Research Report No. 231 (June 2025).
  • Unified the MTRS and SDI-BCA interfaces and CSV layouts.
v1.1.0 2024-11-04
  • Reversal probability of the top-ranked scenario, with the REVERSAL verdict.
  • Cross-area transferability rule driven by alternative metropolitan-area structures, with the NON-TRANSFERABLE verdict.
  • CSV input/output for decision matrices, weights and vintages.
  • Plain-text assessment report renderer.
v1.0.0 — initial release 2024-06-15
  • First implementation of the MTRS procedure following the publication of Research Report No. 212 (May 2024).
  • Six-source uncertainty ensemble: model structure, parameter, data-year, policy-mapping, indicator-weight and area-structure perturbations.
  • Ranking-instability variance decomposition and the stability score S.
  • STABLE / REVERSAL verdict logic with configurable thresholds.

Release numbering: MAJOR.MINOR.PATCH. Patch releases fix defects only and are not listed individually.
