# Changelog

Version history of the MTRS / SDI-BCA reference implementation.

The software was developed internally from 2023 as part of the research
programme documented in NTRP Report 212 and Report 231. The public
open-source release (v1.4.0) was made in November 2026.

## v1.4.0 (March 2026)

- Final internal release; preparation for public distribution
- Packaging metadata, MIT license and worked examples added
- Documentation and validation suite completed

## v1.2.0 (June 2025)

- Extended output formats (JSON, CSV) for downstream tooling
- Additional validation cases for the SDI-BCA staged-delay model
- Performance improvements for large scenario sets

## v1.1.0 (November 2024)

- Staged-Delay-Inclusive Benefit-Cost Analysis (SDI-BCA) model added
- Integrated MTRS + SDI-BCA joint workflow
- Unit test coverage extended

## v1.0.0 (June 2024)

- Initial internal release
- Multivariate Transport Ranking Stability (MTRS) engine
- Core ranking-stability diagnostics for transport scenario evaluation
